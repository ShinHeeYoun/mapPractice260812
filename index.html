Welcome to The Times

This is a simple Java Web Application skeleton running on Tomcat 9. It is designed using a classic black and white newspaper theme. Currently, we are preparing to integrate Google Maps API features.

In the meantime, please enjoy the Whac-A-Mole game from the left menu to test the Single Page Application (SPA) functionality.
